# 🔐 Password Generator

A clean and interactive Password Generator built using HTML, CSS, and JavaScript. This project allows users to generate secure random passwords with adjustable length and copy them instantly.

## 🚀 Features
- 🔢 Adjustable password length using slider (6–24)
- 🔐 Random secure password generation
- 📋 One-click copy to clipboard
- 🎨 Modern and responsive UI design
- ⚡ Fast and simple user interaction

## 🛠️ Tech Stack
- HTML – Structure
- CSS – Styling & layout
- JavaScript – Logic, DOM manipulation

## 📌 How It Works
1. Move the slider to select password length
2. Click the **Generate** button
3. Copy the password using the **Copy** button

## 📷 UI Preview
Simple dark-themed interface with aqua highlights.

## 🎯 Purpose
This project is built to practice JavaScript concepts like:
- DOM manipulation
- Event handling
- Random number generation
